# Реферальная программа · личный кабинет (концепт)

Вёрстка дизайн-концепта страницы реферальной программы в личном кабинете автосалона. Тестовое задание: из прототипа мобильных экранов ТГ-бота собрать стильную десктопную страницу и продумать UX-мелочи.

**Живая страница:** https://maksim431.github.io/jetour-referral/

## Что работает на странице
- Персональная ссылка и рабочий QR-код на неё
- Копирование ссылки с подтверждением
- «Поделиться»: системное меню на телефоне, Telegram / ВКонтакте / WhatsApp на десктопе
- Скачивание правил программы
- Подсказка о том, как начисляются баллы
- Рейтинг с фильтром по месяцу и году, своя строка «вы» всегда видна
- История действий с раскрытием полного списка
- Адаптив: десктоп, планшет и телефон, меню-шторка на мобильных

## Стек
Один `index.html` без сборки: HTML, CSS, ванильный JS. Шрифты Onest и Russo One из Google Fonts, QR через qrcode-generator (cdnjs).

## Дисклеймер
Это концепт. Страница не является официальным сайтом бренда, все имена, телефоны, баллы и события вымышлены.
